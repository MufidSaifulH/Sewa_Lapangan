# Sewa_Lapangan
Tugas Project PPW_2

## Portal akun

- Buka `index.html` melalui localhost untuk masuk atau mendaftar.
- Pendaftaran membuat akun dengan role `user`; setelah login, user diarahkan ke menu lapangan.
- Akun demo admin: `admin@diofidarena.com` / `Admin123!`.
- Keluar menggunakan tombol **Keluar** di halaman masing-masing role.

Data akun disimpan di browser menggunakan `localStorage` dan sesi login di `sessionStorage`. Implementasi ini hanya untuk demo frontend; role dan kredensial dapat dimanipulasi dari browser dan tidak aman untuk penggunaan produksi. Untuk produksi, pindahkan autentikasi, penyimpanan kata sandi, dan pemeriksaan role ke backend dengan database serta HTTPS.
