# DioFid Arena — Sewa Lapangan

Website statis untuk melihat lapangan olahraga dan menyiapkan permintaan pemesanan.

## Halaman

- `index.html` — Beranda
- `lapangan.html` — Daftar lapangan dengan pencarian dan filter
- `detail-lapangan.html?id=<id-lapangan>` — Detail dan formulir pemesanan lapangan
- `cara-pesan.html` — Panduan pemesanan

Buka `index.html` di browser untuk mulai. Data pesanan pada versi ini hanya disimpan sebagai draf di `localStorage` browser; belum dikirim ke server atau menjadi konfirmasi reservasi.
